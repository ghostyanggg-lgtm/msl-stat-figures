# 统计方法说明（给统计师复核用）

本 skill 的计算全部在 `scripts/statfig.py` 里，只依赖 numpy / pandas，不需要 R、SAS 或 lifelines。

## KM 曲线

| 项目 | 方法 | 与哪个软件一致 |
|---|---|---|
| 生存率 | Kaplan-Meier 乘积极限法 | R `survfit` |
| 标准误 | Greenwood 公式（累计风险尺度：Σ d/[n(n−d)]） | R `survfit` |
| 生存率 95% CI | 默认 log-log 变换（`置信区间方法=log-log`，SAS PROC LIFETEST 默认）；可选 log 变换（`置信区间方法=log`，R `survfit` 默认） | R `survfit(conf.type=...)` |
| 中位数 | 曲线首次 ≤ 50% 的时间；恰好等于 50% 且有平台时取平台两端中点 | R `quantile.survfit` |
| 中位数 95% CI | Brookmeyer-Crowley 法：置信下限曲线、上限曲线首次 ≤ 50% 的时间 | R `quantile.survfit` |
| 某时间点生存率 | 该时间点及之前最后一个时间的 KM 估计；超过最长随访时间记为无法估计 | R `summary(survfit, times=)` |
| 组间比较 P 值 | log-rank 检验（多组时自由度 = 组数 − 1） | R `survdiff` |
| HR 及 95% CI | Cox 比例风险模型，Efron 法处理并列事件，Wald 置信区间；不分层 | R `coxph(ties="efron")` |
| 中位随访 | 反向 KM 法（把删失当事件） | 常用做法 |
| 风险人数 | 每个刻度时间点 time ≥ t 的人数 | R `survminer` 风险表 |
| 用日期计算时间 | (结束日期 − 起始日期) 天数；月 = 天 ÷ 30.4375，周 = 天 ÷ 7，年 = 天 ÷ 365.25 | — |

### 验证记录（2026-10-30）

用 R 4.x 的 survival 3.5.8 包，对 6 组随机模拟数据（每组 15–150 例，2 组和 3 组，时间有整数并列和一位小数两种）逐项比较：

- 各组中位数及 95% CI（log-log 和 log 两种方法）：全部一致
- 6 个月、12 个月生存率及 95% CI（两种方法）：全部一致
- log-rank 卡方：全部一致
- Cox 回归系数和标准误（含 3 组）：全部一致
- 另测边界情况（曲线恰好停在 50%、最后一人发生事件）：一致

比较精度：小数点后 5 位。共 94 项，0 项不一致。

### 和原文数字对不上的常见原因

1. **分层 HR**：注册研究常用分层 Cox 模型（按随机分层因素），本工具算的是不分层 HR，两者会略有不同。
2. **置信区间方法**：SAS 默认 log-log，R 默认 log；中位数 CI 会不同。
3. **数据版本 / 分析人群**：ITT、FAS、PP、安全性分析集的例数不同；不同数据截止日期的事件数不同。
4. **时间换算**：天换成月时用 30.4375、30.44 还是 30 天，结果会差一点。
5. **并列事件处理**：SAS PROC PHREG 默认 Breslow，R 默认 Efron，并列多时 HR 略有不同。

本工具发现对不上时，会列为“需要确认”，由使用者决定图上用原文值还是计算值；一张图里不会混用两种来源的数字。

## 森林图

不做任何计算，HR、CI、P 值照抄使用者给的数字。检查项目：

- HR 必须在 95% CI 之内，下限 < 上限，都大于 0
- HR 在对数尺度上明显不在 CI 中点（可能抄错）
- 事件数 ≤ 例数、人数为整数
- 同一亚组各层例数之和不超过总体
- 同一亚组各层填了不同 P 值（可能把各层 P 当成了交互 P）

方块大小按逆方差权重（由 CI 宽度反推），总体行画菱形；横轴为对数尺度。

## 瀑布图

不做计算，按最佳变化百分比从高到低排列。RECIST 1.1 下检查：PR 但缩小不到 30%、CR 但缩小很少、变化 < −100%、疑似把百分比写成小数。填了原文 ORR 时，用（确认的 CR + PR）/ 全部患者 核对。

## 泳道图

不做计算。检查：时长 ≤ 0、事件时间晚于柱子结束、同时标“仍在治疗”和死亡、缓解晚于进展。
